# 🎪 Radhe Krishna Tent House - Enterprise ERP System

A professional, feature-rich, and lightweight Enterprise Resource Planning (ERP) web application designed specifically for Tent House and Event Rental businesses. Built with HTML5, CSS3, JavaScript, and powered by Firebase Realtime Cloud Database.

---

## ✨ Key Features & Modules

* **🔒 Secure Multi-Role Authentication:** Separate secure login dashboards for **Admin** and **Vendor** with password protection.
* **📝 Customer Booking Management:** Create new bookings, track live booking statuses, manage customer details, and calculate automatic deposits & balances.
* **🚀 Dispatch Management:** Seamlessly dispatch items from main stock or vendor stock, with integrated barcode scanning and digital Dispatch Slip printing/WhatsApp sharing.
* **📥 Return & Missing Item Tracking:** Track returned equipment, automatically calculate missing quantities, and apply missing charges to final invoices.
* **💰 Billing & Financial Settlement:** Generate medical/professional-style invoices with custom stamps, automated tax/due calculations, PDF downloads, and UPI QR code payment integration.
* **📦 Smart Stock & Inventory:** Manage equipment inventory with 3D hologram previews, multi-image HD/4K uploads, low-stock warnings, and custom barcode generation/printing.
* **🛒 Purchase & Expense Ledger:** Record supplier purchases, track daily income & expenses, and view real-time Profit & Loss (P&L) analytics.
* **🤝 Vendor Management:** Register external vendors, monitor vendor stock levels, generate vendor bills/challans, and track vendor missing items.
* **📱 Meta WhatsApp Cloud API Integration:** Send instant automated booking confirmations, dispatch slips, and payment reminders via WhatsApp.
* **⚙️ Complete System Settings:** Customize shop branding, developer contacts, terms & conditions, upload official digital stamps, manage cloud backups, and setup automated QR codes.

---

## 🛠️ Technology Stack

* **Frontend:** HTML5, CSS3 (Modern Flexbox/Grid UI, Responsive Design), Vanilla JavaScript (ES6+)
* **Database & Sync:** Firebase Realtime Database (v9 Compat)
* **Libraries & Tools:** 
  * `html5-qrcode` (For live barcode scanning and camera support)
  * `jsPDF` (For client-side PDF invoice generation)
  * PWA Web App Manifest (For mobile standalone app experience)

## 🚀 Deployment

This application is fully optimized for static hosting and cloud deployment. It can be instantly deployed on platforms like **Vercel**, **Netlify**, or **GitHub Pages**.

1. Clone or upload the repository.
2. Ensure `index.html` is located in the root directory.
3. Deploy directly using your preferred static hosting provider.
